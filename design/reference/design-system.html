Open Prism design system

The shared language for Open Prism's LaTeX + AI workspace. Every screen draws from the same tokens, one icon family, and a small set of components so the editor, the assistant, and workspace screens look and behave like one product.

The paper is the heroChrome is neutral and quiet. Colour and serif type are saved for the document and for the one action that matters.
One accent, used sparinglyTerracotta marks the primary action, the current selection, and focus — nothing else.
Panels, not pagesTools live in collapsible side panels around the editor, so writers never lose their place.
Every state is designedLoading, empty, error, read-only and disabled are part of each component, not afterthoughts.

Spacing, radius & elevation

A 4px base unit. Use 8 inside components, 12–16 between related groups, 24+ between sections. Panels are flat: borders separate, shadows are reserved for things that float.

Motion

Motion only explains a change of state — a panel opening, a menu appearing, a toast arriving. Enter with ease-out, exit with ease-in at about two-thirds of the duration. Everything turns off under reduced motion.

--dur-fast 120ms
--dur-base 180ms
--dur-slow 240ms
Fast: hover, press, tooltips · Base: menus, switches, panel collapse · Slow: dialogs, toasts

Icons

One outline family on a 24px grid with a 1.75 stroke, round caps and currentColor. It is Lucide/Feather-compatible, so the inline SVGs already in the editor migrate one-to-one. Icons inherit text colour; status colour comes from the parent.

Markup: <svg class="od-icon"><use href="#i-sparkles"/></svg> — size with --od-icon-size, never with parent selectors.

Icon + label for primary actions; icon-only buttons always get a tooltip and an accessible name.

Form fields

Enter a full email address, like name@university.edu.

Labels always visible above the field. Errors sit under the field, say what went wrong and how to fix it, and appear on blur, not while typing.

Segmented control & tabs

Segmented = switch a mode within the same view (Chat / Agent / Tools, Editor / Split / PDF). Tabs = switch between sibling pages of content.

This is placeholder structure for the hosted model. Each user belongs to one or more workspaces, and every project lives in exactly one workspace. A project role can grant someone more access than their workspace role, but never less.
